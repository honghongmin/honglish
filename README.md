# 홍글리쉬

하루 10분, 친구들이랑 영어 습관 만들기.

매일 다섯 칸을 채우면 하루 학습이 끝나요.

1. 오늘의 단어 5개 (발음 듣기, 사용법, 예문)
2. 복습: 1·3·7·14·30일 간격 반복
3. 생활 회화 문장 3개
4. 영작 3개 (전날 배운 문장)
5. 짧은 아티클 1편 (단어를 누르면 뜻이 나와요)

그 밖의 기능은 레벨테스트(3단계), 주간 단어 테스트, 별표 단어장, 전체 랭킹이에요.

## 파일

- `index.html`, `style.css`, `app.js`: 앱
- `content.js`: 30일 분량 콘텐츠 (레벨별 단어 150개, 문장 90개, 아티클 30편)
- `config.js`: Firebase 웹 설정 (공개해도 되는 값)
- `firestore.rules`: Firestore 보안 규칙 (콘솔에 이미 적용됨)
